
# Zak Nilsen

A personal website for exploring ideas, building things, and chasing wonder between code, nature, and the night sky.

Live site: https://www.zaknilsen.com

## Overview

This project is a digital space for:

- creative work and technical experiments
- projects shaped by curiosity and exploration
- a portfolio story that blends engineering with atmosphere
- interactive visuals, motion, and immersive web experiences
- tools and content inspired by astronomy, wilderness, and the unknown

Built as a modern Next.js experience, the site leans into a cinematic, atmospheric aesthetic with custom interactions and a distinctly exploratory personality.

## Featured spaces

- a cinematic landing experience
- an About page for the story behind the work
- a Projects section for selected builds and experiments
- interactive astronomy and skywatching experiences
- custom animation, motion, and canvas-driven visual layers

## Tech stack

- Next.js
- React
- TypeScript
- Framer Motion
- React Three Fiber / Drei
- Leaflet

## Local development

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```bash
npm run build
npm run start
```
